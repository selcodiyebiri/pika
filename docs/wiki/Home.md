# Pika

**English** | [Türkçe](Home-TR)

Pika is a small, security-minded PHP framework base for personal projects: MySQL (PDO), Blade views, a small router, sessions, CSRF, rate limits, password reset, themes, cron jobs and a command line. It is a starting point to copy and bend, not a general-purpose framework: no ORM, no DI container, no queue.

## Requirements
PHP 8.2+, MySQL 5.7+ or MariaDB, Composer (not needed with the release ZIP), extensions `pdo_mysql`, `openssl`, `mbstring`, `curl`, `fileinfo`.
